⚡ Architecture Specification

OMP-Agent System Architecture

Tổng quan kiến trúc phân tầng: Electron Main ↔ NDJSON stdio ↔ React Renderer ↔ OMP Engine

🖥️ 1. Presentation & Renderer Layer
React 18 + TS + Tailwind + Vite
AgentPanel
ChatHistory, PromptComposer (@file, /slash, images), ThinkingCard, ToolCallCard, SubagentTranscript, TodoPanel.
Canvas Container
Split pane chứa CodeEditor (Monaco), DiffViewer (Git diffs), ArtifactViewer (Live Preview HTML/Doc), TerminalView.
Sidebar & Navigation
ThreadList (đa phiên), ProjectTree (cây thư mục dự án ảo hóa), SubagentHub (quản lý subagent peer).
Custom Hooks
useOmpRpc (stream frame & dispatch), useWorkspace (file sync), useSubagentTranscript.
⬇️ window.electronAPI (ContextBridge - Bidirectional IPC) ⬆️
🔌 2. Electron Host & IPC Bridge Layer
Node.js + Electron Core
OmpBridge (omp-bridge.ts)
Quản lý vòng đời tiến trình con omp --mode rpc, bộ đệm NDJSON (ndjson-framer.ts), log frame, bảo đảm atomic process lifecycle.
Main Process (main.ts)
Đăng ký toàn bộ IPC handlers: omp:*, fs:*, settings:*, native dialogs, window lifecycle.
Supporting Modules
settings-store.ts, host-tools.ts, extension-manager.ts, roles-config.ts, usage-stats.ts.
Preload Bridge (preload.ts)
Expose typed methods an toàn qua contextBridge, đảm bảo renderer không truy cập trực tiếp Node runtime.
⬇️ stdio (stdin / stdout) - Protocol: JSON-Lines (NDJSON) ⬆️
🧠 3. OMP Engine & Core Subsystem
CLI / RPC Daemon (Oh-My-Pi)
RPC Server Daemon
Lắng nghe qua stdio stream với các frame: ready, delta, tool_start, tool_end, approval_request.
Agent & Task Loop
Xử lý prompt, phân rã công việc, quản lý memory session, context window, token usage telemetry.
Tool Execution Core
Thực thi tool an toàn (Read, Edit, Write, Bash, Eval, Glob, Grep, MCP, Browser, Hub peer messaging).
Subagent & Peer Hub
Spawning parallel subagents (scout, task, reviewer), DAG wave coordination, IPC messaging nội bộ giữa các agent.

Vòng tuần hoàn xử lý Message & Tool Approval

1
Prompt Composer
Người dùng nhập tin nhắn kèm @file hoặc /slash, ảnh paste/drop. Gọi electronAPI.ompPrompt().
2
NDJSON Bridge
OmpBridge format frame { type: 'prompt', text: '...' } và ghi vào stdin của tiến trình omp.
3
Streaming Tokens
Engine stream frame delta (text / thinking). Bridge chuyển qua IPC omp:frame → React cập nhật Markdown/Thinking real-time.
4
Tool & Approval
Khi engine cần quyền (file write/bash), phát approval_request. UI hiển thị Card/Modal để người dùng duyệt (allow/deny).
5
Artifacts & Diffs
Kết quả tool trả về: file diffs hiển thị trên DiffViewer, artifact HTML/Doc hiển thị trên ArtifactViewer.

📁 Tổ chức Cấu trúc Codebase (Source Tree)
electron/
main.ts (lifecycle & IPC), omp-bridge.ts (quản lý sub-process stdio), preload.ts (contextBridge), settings-store.ts, ndjson-framer.ts.
src/components/AgentPanel/
AgentPanel.tsx, PromptComposer.tsx (mid-input mention, file chip sync), ChatHistory.tsx, ThinkingCard.tsx, ToolCallCard.tsx, TodoPanel.tsx.
src/components/Canvas/
CanvasContainer.tsx (tab split switch), ArtifactViewer.tsx (preview web/svg/doc với responsive viewport), DiffViewer.tsx, CodeEditor.tsx, TerminalView.tsx.
src/components/Sidebar/
ThreadList.tsx (danh sách hội thoại), ProjectTree.tsx (file tree ảo hóa với filter), SubagentHub.tsx (peer status).
src/hooks/
useOmpRpc.ts (trung tâm điều khiển state engine), useWorkspace.ts (quản lý folder & file tree), useSubagentTranscript.ts.
scripts/
Hệ thống test không dùng test framework bên ngoài: ~24 suite verify-*.mjs chạy với Node native test assertion.
1. The Main Process is Sacred
Không bao giờ dùng sync child process (execSync/spawnSync) trong Electron main để tránh block event loop UI.
2. Contracts are Tests
Mọi IPC channel, frame shape trong omp-rpc-types.ts đều được khóa bằng các script verify-*.mjs.
3. The UI Never Lies
Mọi lỗi khởi động engine hoặc timeout đều phải hiển thị Toast rõ ràng cho người dùng, không bao giờ nuốt lỗi âm thầm.
4. Scale is the Default Input
Workspace giả định có hàng nghìn files: bắt buộc dùng React.memo, cap render, virtualization để tránh drop FPS.
5. Symmetry of State
Bất cứ menu, modal hay inline chip nào mở ra đều phải có cơ chế đóng/xóa hoàn toàn đối xứng trên mọi đường thoát.
6. Real Behavior Only
Không sử dụng fake mock data trong môi trường chạy thật; chỉ duy trì mock tối thiểu khi chạy trình duyệt không có Electron.
